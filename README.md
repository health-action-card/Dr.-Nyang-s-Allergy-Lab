# 냥박사의 알레르기 연구소 · 나만의 알레르기 방패

초등 보건 수업용 웹앱이에요. 연구소(S00~S38A)에서 알레르기 유발물질 12가지를 찾고, 증상과 대처 방법을 익혀요. 그다음 알레르기 방패(S39~S49)에서 예방 약속 카드를 만들고 5일 챌린지를 해요.

- 서버 없이 동작하는 정적 웹앱(PWA)이에요. GitHub Pages에 이 폴더를 그대로 올리면 돼요.
- 학생 기록은 각 기기의 LocalStorage에만 저장되고, 밖으로 보내지 않아요.
- 태블릿은 1600×900 화면을 기기 크기에 맞춰 확대·축소해요. 휴대폰에서 연구소는 가로로, 방패는 세로로 봐요.

## 화면 흐름

```
S00 첫 화면 → S01~S04 이야기 → S05 활동 선택
 ├ 알레르기 완벽 파악 → 집 S06(S07~S14) → S14A → 급식실 S15(S16~S23) → S23A
 │                    → 운동장 S24(S25~S32) → S33 → S36-1 → S36-2 → S36-3~6 증상 카드
 │                    → S37 ⇄ S38 대처 방법 → S38A 기억 체크 → S39
 └ 나만의 알레르기 방패 → S39 → S40 → S41 → S44 → S45 → S46 → S47 → S48
선생님 설정(S49): S00 냥박사 또는 간판을 3초 안에 5번 터치 (행사용 기기는 S39 제목 배너)
```

## 연구소를 만든 방식

지금은 부품 그림(투명 PNG)이 없어서, **장면 그림을 바탕으로 깔고 그 위에 코드로 얹는 방식**이에요.

- **누르는 자리**: 바코드, 물체, 버튼 위에 투명 버튼을 얹어요 (`lab-hot`).
- **바뀐 글자**: 그림 속 "클릭해 보세요" 같은 글자는 흰 상자로 덮고 새 글자("눌러 보세요")를 써요 (`lab-cover`).
- **예방 수칙**: 증상과 예방법 화면의 예방법 상자는 코드로 다시 그려요. 수칙은 `lab-items.js`에서 고치면 돼요.
- **이름판**: "냥이연구소"는 "냥박사의 알레르기 연구소" 이름판으로 덮어요 (`lab-sign`).
- **트레이**: 못 찾은 칸은 회색 필터로, 찾은 칸은 ✓로 표시해요.

좌표는 모두 **그림 기준 %**로 적혀 있어요. 형식은 `[왼쪽, 위, 너비, 높이]`예요.

### 부품 그림으로 바꾸고 싶을 때
1. `assets/lab/`에 새 그림을 넣어요.
2. `data/lab-items.js`의 `img`(장면 그림)와 좌표를 새 그림에 맞게 고쳐요.
3. 장면 그림을 다시 만들면, 덮어 둔 글자(`bubble`, `fix`, `ribbon`)가 필요 없을 수 있어요. 그 항목은 지우면 돼요.

### 글자 표시 규칙 (`lab-items.js`)
- `[글자]` = 파란 굵은 글씨
- `{{글자}}` = 분홍 굵은 글씨
- `<br>` = 줄바꿈

## 저장 키 (LocalStorage)

| 키 | 내용 |
|---|---|
| `promiseCard.labFound` | 장소별로 찾은 유발물질 `{home, school, ground}` |
| `promiseCard.labComplete` | 연구소를 마쳤는지 |
| `promiseCard.*` (그 밖) | 방패 약속 카드, 5일 챌린지 기록 |
| `appConfig` | 선생님 설정 (수업용/행사용, 게시판 주소) |
| `appSound` | 효과음 켜기/끄기 |

증상 카드, 대처 방법 확인, 기억 체크 진행 상태는 앱 메모리에만 있어요. 앱을 다시 켜면 그 부분은 처음부터 해요. `promiseCard.`로 시작하는 기록은 S48-3 기록 삭제와 S39 새로 만들기 때 함께 지워져요.
